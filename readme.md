# Kaithal Travel Support 🧳

An AI-powered chatbot that answers customer questions for a tour and travel business based in **Kaithal, Haryana**. It helps visitors learn about tour packages, plan trips, and get in touch with the team quickly.

## Features

- 💬 Instant answers to customer questions about tours and bookings
- 🗺️ Information on **All-India Tour Packages**
- 👨‍👩‍👧 **Family Tours** and 👥 **Group Tours**
- 🛕 **Religious / Yatra Tours**
- 📞 Easy access to business contact details
- ⚡ Fast responses powered by the Groq API

## Tech Stack

| Part | Technology |
|------|------------|
| AI / LLM | [Groq API](https://groq.com) |
| Development | Replit |
| Hosting | Vercel |

## Getting Started

### 1. Clone the project

```bash
git clone <your-repo-url>
cd Kaithal-Travel-Support
```

### 2. Install dependencies

```bash
npm install
```

> If your project uses Python, run `pip install -r requirements.txt` instead.

### 3. Set up environment variables

Create a `.env` file in the project root:

```env
GROQ_API_KEY=your_groq_api_key_here
```

Never commit your API key to GitHub.

### 4. Run locally

```bash
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Deployment (Vercel)

1. Push the project to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. Add `GROQ_API_KEY` under **Settings → Environment Variables**.
4. Click **Deploy**.
